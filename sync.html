🧱 ดึงรูปจาก LEGO.com → ไฟล์ JSON

กำลังโหลดรายการเซ็ต…

1 · เลือกขอบเขตเซ็ตที่ต้องการ

2 · ดึง URL รูป

เครื่องมือนี้ต้องรันในเบราว์เซอร์ของคุณ (เปิดหน้านี้บนมือถือ/คอมที่บ้าน) เพราะ vavario ถูก lego.com บล็อก — แต่เบราว์เซอร์ของคุณไม่โดนบล็อก

ถูกบล็อกโดย CORS (เบราว์เซอร์กันการเรียกข้ามโดเมน) — ใช้ขั้นตอนที่ 3 ด้านล่างแทน

3 · ถ้าอัตโนมัติไม่ผ่าน: รัน snippet ใน Console บน lego.com

  1. เปิด www.lego.com (หน้าไหนก็ได้)
  2. กด F12 (คอม) หรือใช้เบราว์เซอร์ที่ Inspect ได้ → เปิดแท็บ Console
  3. กดปุ่มด้านล่างเพื่อคัดลอก snippet → วางใน Console → กด Enter แล้วรอจบ
  4. ผลลัพธ์จะอยู่ในคลิปบอร์ดอัตโนมัติ — กลับมาวางในกล่องขั้นที่ 4
(เลือกขอบเขตก่อน)

4 · วางผลลัพธ์ → ได้ไฟล์ JSON

วาง JSON จากคลิปบอร์ด หรือหยดไฟล์ .json ลงกล่องนี้
